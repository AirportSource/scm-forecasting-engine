# Learning log

Trace légère de ce qui a réellement été appris, produit et laissé fragile. Le but n'est pas d'écrire un journal long.

## Entrée quotidienne

```markdown
### YYYY-MM-DD · Bx · X h XX

**Fait** — une phrase.

**Preuve** — commit, fichier, exercice, résultat ou issue.

**Compris**
- 1 à 3 points avec mes mots.

**Fragile / à revoir**
- notion ou erreur précise.

**Première action demain**
- une action exécutable en moins de 10 minutes.
```

Les heures sont des heures de travail réel, pas les heures passées devant l'écran.

## Revue hebdomadaire

```markdown
# Semaine YYYY-Wxx · Bloc Bx

- Heures : __ / 40 planifiées
- Preuves principales :
- Issues fermées avec preuve :
- Skills montées de niveau :
- Fragile / rappel :
- Heures hors bloc courant :
- Budget du bloc : __ consommées / __ prévues
- Objectif unique semaine suivante :
- 3 issues maximum :
```
